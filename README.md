# Floodlight

**Every moment, under the floodlights.**

Floodlight turns synthetic football match data into explainable match
intelligence, automated broadcast direction and personalized stories — live,
in one pipeline. It is a complete, self-contained production of the whole
path: match events → football physics & statistics → multi-agent
explanation & verification → timed broadcast cues → per-fan experience.

All clubs, players and matches are fictional. Every match is generated by a
seed and is fully reproducible.

## The pipeline

| Stage | What happens | Where |
| --- | --- | --- |
| **Ingest** | A seeded simulator plays a full 90 minutes as a stream of typed events (passes with difficulty & outcomes, carries, duels, shots with xG, set pieces, cards, substitutions, VAR reviews) plus a derived 10 Hz positional feed. | `packages/simulator` |
| **Interpret** | A deterministic football intelligence engine reduces the stream to live states: possession phases, pass quality, control-vs-chaos, tactical pressure, rhythm and momentum. | `packages/engine` (in progress) |
| **Explain** | A multi-agent production crew (Director, Analyst, Commentator, Verifier, Personalizer) turns moments into evidence-cited explanations and audience-shaped narratives. Nothing without evidence reaches air. | `packages/agents` (in progress) |
| **Render** | Approved stories compile into a versioned, timed, machine-readable cue sheet (lower thirds, stat bumpers, telestration, momentum ribbon) ready for a graphics renderer. | `packages/cuesheet` (in progress) |
| **Personalize** | The same verified intelligence reaches an analyst, a casual fan, a club supporter or a player-focus viewer — in their language, with their club and their metrics. | `packages/agents` (in progress) |

A companion vision pipeline re-derives events from rendered match frames
(auto-eventing) and reports its accuracy against ground truth — the dataset
validates its own perception layer.

## Data

The simulator generates a football-realistic synthetic dataset. Aggregate
texture is verified against realistic ranges on every test run (20-match
fixture): ~3.4 goals, ~26 shots, ~82% pass accuracy, ~17 fouls, ~8 corners
per match, with seeded reproducibility — the same seed yields the
byte-identical event stream on any machine.

Scripted storylines (`comeback`, `siege`, `derby`) choreograph dramatic
matches — including a VAR overturn — so the intelligence pipeline always has
a real story to discover, explain and retract.

## Quickstart

```bash
npm install
npm test          # deterministic test suite (simulator, engine, agents)
```

```ts
import { simulateMatch, SCENARIOS, summarizeMatch, trackingWindow } from '@floodlight/simulator';

const result = simulateMatch(12345, SCENARIOS.find((s) => s.id === 'comeback'));
console.log(summarizeMatch(result).goalsHome);   // full-time score
const frames = trackingWindow(result, 600, 660); // 10 Hz positional feed
```

## Principles

- **Deterministic**: seeds everywhere; identical inputs, byte-identical
  outputs. Tests assert reproducibility, not just plausibility.
- **Evidence first**: every number in the product traces back to an event in
  the stream. The verifier rejects claims that cannot cite their evidence.
- **No real data**: fictional league, fictional clubs, fictional players —
  football-realistic, fully synthetic.
